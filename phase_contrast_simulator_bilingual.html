本模擬使用的物理模型

t(r) = 2√(R² − r²), r ≤ R　;　φ(r) = (2π/λ₀)(nₛ − nₘ)t(r)
δ = (2π/λ₀)(nₚ − nᵦ)h　;　H(fₓ,fᵧ) = P(fₓ,fᵧ) [1 + (exp(iδ) − 1) M(fₓ,fᵧ)]
U_CCD ∝ ℱ⁻¹{ H · ℱ[exp(iφ)] }　;　I_CCD = |U_CCD|²

以 ABCD 透鏡矩陣定位物體的 Fourier-conjugate plane 與 CCD 像平面；假設傍軸、理想薄透鏡、平面波入射、薄相位物體、均勻介質、純相位 Phase Spot 和圓形有效 pupil。FFT 在物平面座標計算，CCD 影像顯示已換算回物方尺度。模型沒有模擬球體大折射率差造成的強折射／Mie 散射、鏡頭像差、真實相機雜訊或相位量測反演。

若 PS 設為 0，對照圖只剩有限 NA 造成的 coherent diffraction。相位板改變的是參考光和散射光的相對相位，不是直接把物體厚度轉成灰階；強相位可能出現亮暗反轉，不能以單張影像唯一解出厚度。
